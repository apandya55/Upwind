# UPWIND isolated frontend sandbox

This directory is a standalone React/Vite workspace for the Opus landing-page pass. It uses local screenshots only and has no connection to the product API.

Read `OPUS_FRONTEND_PROMPT.md` for the implementation brief. Start the preview with `npm run dev` from this directory; it uses `http://127.0.0.1:4178`. Run `npm install` here if this checkout does not expose the parent frontend's installed packages. Verify with `npm run build`.

All work for this isolated experiment should stay in this directory.
