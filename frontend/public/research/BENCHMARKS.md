# UPWIND export and spatial benchmarks

Generated by `scripts/export_and_benchmark.py`. No network acquisition is performed.

## Data and ingestion

`backend/upwind/store.py` stores investigation JSON in SQLite; it is not a normalized observation warehouse. This export uses the national EPA annual release built by `scripts/build_national_dataset.py`. Ingestion selects complete parameter 88101 annual summaries, prioritizes the latest standard, retains Events Included or No Events per POC, then averages colocated POCs. Hourly intake (`scripts/acquire_aqs.py`) is a separate pipeline. This is annual NC data, not hourly measurements. Exact duplicate site-years are removed; conflicting duplicates abort. Rows with invalid required values are counted and dropped. Finite negative PM2.5 values are retained without clipping.

```json
{
  "input_national_rows": 6763,
  "input_nc_rows": 160,
  "rejected_nc_rows": 0,
  "duplicate_nc_rows_removed": 0,
  "export_rows": 160,
  "sensor_count": 23,
  "date_start_inclusive": "2018-01-01",
  "date_end_exclusive": "2026-01-01",
  "bbox_west_south_east_north": [
    -83.442133,
    34.364167,
    -77.360126,
    36.511708
  ],
  "weather_nonnull_counts": {
    "temperature_c": 0,
    "relative_humidity_pct": 0,
    "wind_speed_m_s": 0
  }
}
```

Weather is left-joined by physical site ID and year only when `--weather` is supplied; no imputation or inferred temporal matching. Without that file, all meteorological columns are null. Sensor-fusion accuracy cannot be tested with this release: it has no matched weather or independent sensor-fusion targets.

## Spatial accuracy

NC-only, within-year five-fold spatial cross-validation using a fixed SHA-256 assignment of one-degree cells (UPWIND-NC-1:floor(lat):floor(lon), first eight hex digits modulo five). The national ten-degree protocol places NC sites in one fold and cannot support NC-only training; this regional split uses smaller cells. Each station retains its earliest coordinate's fold across all years. Entire held-out folds are excluded from training. Predictions call `scripts/evaluate_national_v2.py` directly; nearest monitor is the released method and IDW/kernel ridge are candidates. No parameters are tuned here. EPA annual site summaries are the reference targets, not a claim of independent FRM-only instruments. This is a regional re-evaluation, not the published national score or a future-year forecast. MAE = mean(abs(predicted − observed)); RMSE = sqrt(mean(error²)); R² = 1 − SSE/SST using the test-set mean. R² is undefined for fewer than two targets or constant targets. Pooled scores weight site-years equally; repeated years are not independent stations. Small regional folds limit generalizability; 2025 observations are provisional.

## Query latency

Warm in-process full-result bounding-box queries: linear scan versus the production one-degree bucket index in `backend/upwind/national/data.py`. This does not add a SQL index or modify the application database. 100 seeded station-centered windows, half-width 0.05–1 degree, alternating execution order each repetition. All results are checked for exact equivalence before timing. Indexed timing includes production file-identity checks; index build excludes JSON parsing. These small NC data may be faster to scan. Timings vary by machine and load.

```json
{
```
