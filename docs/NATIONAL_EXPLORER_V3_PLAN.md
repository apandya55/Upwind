No two workers edit the same file. Workers do not spawn additional agents. Existing v0.9 inverse-source engine code, tests, protocols, reports, raw investigations, and evaluation outputs are out of scope and must remain untouched. Existing national release inputs and generated JSON are also preserved unless a verified pipeline repair requires rebuilding; rebuilds must be reproducible and retain provenance.

## Backward-compatible estimate and API contract

Keep the existing `/api/national/manifest`, `/places`, `/monitors`, and `/sources` routes and existing response keys. Place responses remain `{items, total, year, truncated}`. Every place item retains its Census fields: `id` (GEOID), `name`, `state`, `state_fips`, `place_type`, `latitude`, `longitude`, `estimates`, and optional `population_vintage`. `model_estimates[year]` is optional; absence means no supported estimate. Existing estimate fields remain: `value_ug_m3`, `interval90_low_ug_m3`, `interval90_high_ug_m3`, `nearest_monitor_km`, `reference_monitor_id`, `reference_monitor_value_ug_m3`, `model_id`, `support`, `evidence_status`, `estimate_latitude`, and `estimate_longitude`.

For exports and any new snapshot response, make the same meaning explicit without renaming those fields: place identifier/name/state/type; WGS84 estimate coordinates and the fact that they are Census Gazetteer internal points; pollutant PM2.5, µg/m³, analysis year; value, method/model version and evidence status; supporting-monitor distance/ID/value; lower/upper bounds and their empirical spatial out-of-fold interpretation; dataset source/vintage and release build timestamp. Unsupported places export an explicit missing estimate and reason when the manifest provides it; they are never assigned a fabricated value. Monitor records remain measured AQS annual summaries, facility records remain EPA NEI inventory estimates, and neither is merged with place estimates. GeoJSON coordinates are `[longitude, latitude]` in WGS84. CSV values must be spreadsheet-safe.

## Bounded modeling experiment

Before fitting, audit site identity across years, duplicate instruments/POCs and event handling, target units and completeness, geographic fold grouping, training-only preprocessing, predictor vintage/availability, and whether 2024/2025 eligible-site completeness differs. Existing 2024 and provisional 2025 outcomes have been inspected; they cannot be relabeled untouched. If eligible site-years from a genuinely uninspected vintage exist, reserve them before development; otherwise report development results only and keep that limitation.

Write down any protocol revision before running it. Compare only nearest monitor, the existing fixed 150 km Gaussian candidate, and at most one candidate using an acquired, licensed, aligned environmental predictor. Keep every physical AQS site grouped into one geographic fold, use identical evaluation rows, and fit all transformations on training data only. Use a small fixed fold count and no broad parameter search. Report MAE, RMSE, bias, fold variation, sample counts, errors by distance to supporting monitors, and 2024/2025 completeness. Quantify the nominal level, observed coverage, and width of the current ±4.059 µg/m³ empirical OOF band, with only stable broad strata. If no verified predictor is obtainable, document the access/provenance blocker and stop that branch. Do not tune to old held-out results or weaken the existing model-selection rule.

## Release acceptance

The integrated app must run from documented local commands on the existing real release. Visible values, API data, snapshot endpoints, CSV, GeoJSON, and print output must agree. The national raw dataset must stay out of the initial browser bundle. Verify supported and withheld places, unique-place population aggregation, source record provenance, representative API time/payload, build/release size, frontend production build, an integrated relevant backend test run, and focused browser flows for search, layer/legend, comparison, URL restoration, exports/print, withheld place, failed map/data requests, and mobile layout. Record failures and scientific limits rather than presenting them as solved.
