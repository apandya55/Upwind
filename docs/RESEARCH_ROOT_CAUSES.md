## Audit and reference qualifications

[stage1-corrected](../evaluations/research/stage1-corrected/) uses the generator's actual regional background trend `(epoch-1.5)/3`. The original auxiliary script incorrectly used epoch-scaled background; its outputs/correction are preserved. Background-only placeholder coordinates are not source truth, so their localization-error fields must be ignored. These diagnostic oracles do not reveal true individual instrument bias/discrepancy realizations to their fits.

The bounded source-count reference corrects arange endpoint overshoot/undershoot in the original auxiliary grid and checks pair losses independently against scipy.nnls. It is a finite, potentially nonconverged profile reference, not an exact posterior or an operational multi-source inference engine. Do not infer noise-free identifiability solely from one grid or interpret a point estimate's error as geographic coverage.

`development-joint` completed288 old/new outcomes and400 follow-ups with zero crashes, but source hashes changed during active formatting, evaluator additions and the40-sensor diagnostic correction. It is deliberately development-used, never a frozen final result. The development perturbation run similarly retains its hash drift. Calibration/final use the subsequent candidate freeze. The initial browser test used a button available only in the Plan tab; the corrected workflow has an accessible Analyze current study action in Scenarios. An early API test expected the wrong refusal status; the actual documented `insufficient_data` response remains unchanged. Failed artifacts are retained.

## Research grounding and limits

The actually inspected primary/official sources and pinned revisions are in [ENGINE_RESEARCH.md](ENGINE_RESEARCH.md). This turn also inspected Stan's `problematic-posteriors.qmd` at revision235171991f7040b0b0ebb59e974d1299af5a049b: ridge-like nonidentifiability is not removed merely by making a prior proper. That is methodological guidance, not evidence about these source coordinates. No quoted field benchmark is supplied by a general Bayesian workflow reference.

Official NOAA DATEM and Sagebrush retries still return proxy CONNECT403, retained [verbatim](../evaluations/research/external-retry.json). The inspected official NOAA utilhysplit checkout contains DATEM parsers but no verified Sagebrush controlled-release measurements. London rows lack verified source truth/geometry and remain a data-quality audit. No measured localization, field adequacy or regulatory reliability has been demonstrated.

A rejected auxiliary hypothesis is preserved in `source-count-rank/`: an initial parameter-count argument assumed six old development monitors. The actual old development layout has **seven** monitors (calibration/final have six). Corrected true-state Jacobians for three old two-source cases have rank8/8, so there is no dimension-count proof of local nonidentifiability. Small normalized singular values and the global profile/noise evidence must be interpreted on their own; no structural-impossibility assertion is made. New campaign controls have six monitors across different winds; repeated geometry under one wind and diverse-wind geometry are separate experiments.
