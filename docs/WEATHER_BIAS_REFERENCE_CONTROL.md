This is an additional diagnostic control, not a model change, calibration result or replacement primary test.

The legacy0.4 adapter preserves originally observed primary weather and cannot interpret paired-comparison metadata. That is a legitimate application-capability comparison, but a new-vs-old comparison on characterized weather combines data-use and inference differences. No comparison reading is invented, averaged into noiseless truth, or acquired free: these reference readings were existing inputs available to the repaired model too.

Compare with primary0.5 risk/information and all baselines only after outcomes are saved. This tests whether good observed weather could help the old implementation as well; no claim of a pure algorithm advantage may rely on denying available references to the old model.
