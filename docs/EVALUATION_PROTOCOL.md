# Frozen initial evaluation protocol

Defined before running held-out evaluations. Engine v0.1 is evaluated on seeds 101, 202, 303 for each bundled case, separate from the UI's seed 42. No parameter fitting to these seeds is permitted without revising this protocol and marking previous results exploratory.

Metrics: distance of maximum-weight candidate to hidden source (metres), number and area proxy of candidates covering 90% conditional weight, truth inclusion in that discrete set, held-out predictive RMSE after withholding the last sensor entirely, optimized score and plan cost, mean random score over 20 seeds, spread and wind baseline score, and measured runtime. Discrete region area is an approximate convex-hull area; a single candidate has zero area and does not imply geographic certainty. Point-grid coverage is conditional on truth being in the candidate set.

Cases: identifiable, ambiguous, noise, missing sensors, changing background, calm wind, multiple sources (deliberate mismatch), variable wind. All are SYNTHETIC, including meteorology. Expect calm/variable winds and missing-sensor inference to be refused; ambiguous cases should remain uncertain. Sharp but wrong results and failed or unavailable metrics must be retained. Baseline comparison uses the same permissible candidates, costs, equipment and windows. Information score is an approximate planning utility, not observed localization improvement. This release does not yet establish prospective planner benefit from independent follow-up measurements.

The held-out sensor never contributes to posterior fitting; its weather is used only to evaluate predictions at already observed timestamps, not as a forecast. True source/strength are separate evaluator metadata, never inference fields. Inference still sees a predeclared location grid that happens to contain synthetic truth. No real-world uncertainty calibration, chemical-source attribution, external partner validation, or independent tracer validation is claimed.
